## Java GradeBook (Console App)
A Java console gradebook that lets a user add, remove, and view grades, and calculate the average score.

## Features 
- Add a grade (0–100 validation)
- Remove a grade by course name
- List all recorded grades
- Show average score

### How to run (IntelliJ)
1. Open the project in IntelliJ IDEA.
2. Run `MainGradeBook.java`.

##Example 
1. Add a grade
2. Remove a grade
3. View all grades
4. View average score
5. Exit
